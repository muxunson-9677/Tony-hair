# 示例人物素材说明

## 用途与边界

`public/demo/` 内的九张 WebP 均为本项目制作的 AI 生成虚构成年东亚人物素材，不对应真实人物，也不是用户照片。它们只用于“示例体验”：帮助访客比较短发轮廓、现实可剪性和打理成本。

这些图片是随应用发布的固定素材，不是根据访客照片生成的结果，也不能展示或描述成用户生成结果、真实预测、真人剪前剪后对比或个性化推荐。界面中的现实可剪性和打理信息是预写参考，最终方案需理发师现场确认。
