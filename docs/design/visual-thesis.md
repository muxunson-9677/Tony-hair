# “咋剪发”Apple Light 移动体验论点

## Visual thesis

界面是一款以手机为主的私人发型工具。柔和白色与浅灰负责安静承载内容，深灰文字建立秩序；珊瑚红、系统蓝、柔紫和薄荷绿只用于小图标和状态反馈。人物照片仍是内容主体，透明毛玻璃只服务于导航、筛选浮层和临时操作坞，不把长表单、档案正文或照片卡变成层层玻璃。

交互遵循直接操控：手指按下时控件立即轻缩，移出热区取消，移回恢复；松手用短促弹性回到原位。可横向滚动的筛选与收藏夹支持一比一拖动、边缘阻尼和保留速度的收尾。动画提供空间与状态反馈，不用来炫技。

这不是公开灵感广场：没有作者、热度、点赞数或社交关系。精选内容明确标注为项目内 AI 合成成年人物正面示例，收藏和收藏夹只保存在当前设备。

## Content plan

- **首页：** 品牌、口号和一张明确标注来源的短发正面示例先建立方向；随后只给一个由本地档案状态计算出的首要动作，并保留去发型库的次级入口。用户先知道“现在该做什么”，再浏览功能。
- **找发型：** 六个精选方向以图片为主。条目只显示名称、维护成本和一条现实提示；搜索、目标和维护筛选帮助处于知识盲区的用户缩小范围。
- **发型详情：** 大图之后依次说明适合条件、维护成本、现实取舍和可直接给理发师看的完整要点。底部操作坞连接已经实现的加入计划、给理发师看、收藏与返回。
- **我的收藏：** 收藏夹用于本机私人整理，可创建、重命名、删除和移动收藏；空状态解释下一步，而不是伪造内容。
- **档案与我的：** 既有档案流程保持可达；“我的”压缩为头发档案、理发档案和照片遮罩三个可执行入口，并明确设备本地存储边界。

## Interaction thesis

1. 首页主操作由 `resolveHomeAction` 依据档案、计划、沟通卡和剪后回传状态决定；冲突按恢复真实闭环优先，不用静态营销按钮冒充智能建议。
2. 移动端底部导航和详情操作坞保持稳定；桌面端改为横向顶部导航。两者都使用带实色回退的轻量玻璃，让控制与内容分层。
3. 发型库筛选在桌面端保持可见，在移动端自然进入正文；结果为空时提供明确重置，非法或退役 ID 进入诚实终止页，不以其他发型顶替。
4. 收藏按钮使用 `aria-pressed` 表达状态，所有主要控件可键盘操作；路由只做短促淡入，`prefers-reduced-motion: reduce` 下关闭非必要动画，`prefers-reduced-transparency: reduce` 下玻璃回退成实色白面。

## Layout guardrails

- 390px 移动视口采用两列图片流，首屏至少看完两个条目并看到下一行延续；不为塞入三列牺牲名称和现实提示。
- 900px 起进入真实宽屏布局：顶部导航、粘性筛选区和至少三列结果，不把移动页面简单居中成窄手机条。
- 内容面使用白色与浅灰实色面和照片；毛玻璃仅用于导航、详情操作坞、图片悬浮按钮等短暂停驻的控制层。
- 系统中文字体优先，通过字号、字重、分隔线和留白建立层级；彩色只用于小图标与关键状态，不使用深色数据仪表盘、霓虹边缘或玻璃套玻璃。
- 触控目标不低于 44px；字体放大、无 `backdrop-filter` 和减少动态效果时仍需保持完整内容与清晰层级。
