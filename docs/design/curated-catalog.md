# 精选发型目录说明

## 素材来源

首批精选固定为 6 款，全部使用 public/demo/ 中现有的项目内 AI 合成成年人物造型图。它们是随应用发布的同源静态 WebP，不是网络抓取、热链、用户照片或真实顾客案例，也不会写入 IndexedDB 或调用接口。

目录以 src/features/hairstyle-library/curatedCatalog.ts 为名称、别名、筛选条件、维护成本、现实限制和理发沟通要点的单一来源。条目 ID 与图片路径发布后不得复用；未来若下架，保留原条目解析能力，只从新浏览入口隐藏。

## 画面边界

六张造型图均为 900×1125 的 4:5 竖图，且仅有正面视角。它们可帮助用户比较大致轮廓，不能证明侧面、鬓角、后脑或真实头型上的最终效果。

产品文案必须明确显示“AI 合成成年人物示例”和“侧面和后脑细节需理发师现场确认”。不得声称提供侧面或后脑图片，不得从正面图伪造其他角度，也不得把预写的可剪性说明描述成对个人的确定判断。

## 搜索与筛选语义

搜索覆盖发型名称、唯一别名、七类用户目标和维护描述。多个搜索词必须同时命中；多个目标也必须同时满足。维护等级与发质在各自组内采用任一匹配，不同筛选组之间同时生效。默认结果只包含 active 条目，并保持策展顺序。

发质、发量、发丝粗细只表达可能的适配条件，不构成脸型诊断或最终可剪承诺。每款的取舍和理发师沟通字段仍需结合用户本人发旋、头型、发际线与现场沟通使用。
