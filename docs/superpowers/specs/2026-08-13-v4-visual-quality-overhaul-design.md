# V4 品质返工总纲：亿级低门槛 × 苹果级工艺（v2，含拓展调研）

日期：2026-08-13
触发：产品负责人验收否决。不止"词汇抽象"和"UI 太平"两个点，而是以"巨量影响力、高质量内容、轻理解门槛、高效精准、品质感"为标准全面返工。

## 0. 调研结论（本轮设计的依据）

| 来源 | 拿来用的结论 |
| --- | --- |
| 工信部《APP 适老化通用设计规范》 | 硬指标：主要文字 ≥18dp、主界面最大字体 ≥30dp、对比度 ≥4.5:1、主要组件点击区 ≥44×44（适老 60×60）、焦点状态必须明显、区域靠**色彩差异**辨识、忌复杂纹理装饰、无诱导按钮 |
| Apple HIG / WWDC 设计原则 | 内容层与控制层分离；层级靠字重+间距+对比；Simplicity≠Minimalism（白话不是删字）；craft=每个间距都能说出理由 |
| Airbnb DLS（2016→2025） | **照片是主角，界面退后**：白上白 + 圆角裁切照片 + 一档柔和海拔就够；一个强调色只留给主行动；2025 转向"有体积的现代拟物"——图标可触摸、卡片有厚度 |
| Duolingo | 先体验后注册（play first, profile second）；情境式引导（该出现时出现的一句话）代替前置教程 |
| 微信/张小龙 | 一个界面只做一件事；自然=不用想；诚实（不做已读回执式的焦虑设计）；用完即走 |
| 美发类产品死因研究 | 做"店家的工具"全死（O2O 平台、门店小程序）：低频+地域+理发师不缺客源；功能堆砌"员工不会用、客户看不懂"；行业信任危机（办卡/推销/虚头衔）**恰是用户侧工具的机会** |

**产品身份句**（全部设计决策的锚）：这是**用户自己的**理发记忆与沟通工具——不办卡、不推销、不上传；到店 10 秒说清楚，剪完一辈子记得住。

## 1. 视觉论点（一句话）

真实发型照片做每一屏的主角，界面是一张安静的浅灰纸面；白卡片有真实厚度（一档柔影+圆角裁切），文字大而黑、层级靠字重；一个品牌蓝只出现在"下一步该按的键"上；所有靠眼睛的选择都画出来。

## 2. 设计系统 v2（tokens）

- **纸面**：页面背景 `#e9edf2`（与白卡拉开两档明度），保留极淡品牌氛围光；忌纹理。
- **海拔**：`--elev-1`（列表项/次卡）、`--elev-2`（主卡）、`--elev-3`（悬浮主行动/导航）。多层柔影 = 环境影 + 接触影 + 1px 边线 + 顶部高光；照片一律圆角裁切（12–20px）。
- **文字**：移动端正文 17px（≥18dp 等效）；页面标题 30px+/850/-0.02em；分区标题 20px/800；辅助字 `#525a64`（≥7:1）；正文行高 1.55。
- **色彩**：一个品牌蓝 `#3478f6` 只给主行动与选中态；区域辨识用色彩差异（步骤号的蓝/珊瑚/薄荷已有）；红只给避雷/危险。
- **控件**：主按钮 52px 高、垂直渐变、色影、顶部内高光（键程感）；瓦片选择 ≥72px；焦点环 3px 明显。
- **动效**：保留 tactile 按压；选中勾弹入 160ms；`prefers-reduced-motion` 全静态。

## 3. 零门槛选择（OptionCards）

规则：**用户在选一个视觉概念时，选项必须把这个视觉概念画出来**；文字只做确认——主标签 ≤5 字白话 + 一句人话解释。

- `src/ui/OptionCards.vue`：fieldset+legend、原生 radio（隐藏可聚焦）、大瓦片 label 网格、选中=蓝环+角标勾；键盘/读屏可用。
- `src/ui/OptionArt.vue`：SVG 线稿图集——发丝形态（直/弯/卷/小卷）、粗细（三档线宽）、发量（疏密簇）、呈现感觉（圆润曲线/利落折线/两者并置）、洗发频率（7 日点阵亮 7/4/2.5/1 天）。
- 白话文案对照（存储值一个不改）：

| 字段 | 旧 | 新 |
| --- | --- | --- |
| presentationPreference | 偏柔和 | **柔和一点**·线条圆润，看起来温柔 |
| | 偏利落 | **利落一点**·线条干净，看起来精神 |
| | 中性 | **中性都行**·不偏向哪一边 |
| | 都可以 | **都可以**·两种都帮我看看 |
| hairTexture | 直 | **直发**·自然垂下来 |
| | 微卷 | **有点弯**·自然的弯度 |
| | 卷 | **卷发**·一圈一圈 |
| | 强卷 | **小卷很密**·卷得很紧 |
| strandThickness | 细 | **发丝细**·摸起来软 |
| | 适中 | **不粗不细** |
| | 粗 | **发丝粗**·摸起来硬 |
| density | 少/适中/多 | **偏少 / 正常 / 很多** |
| washFrequency | 下拉 4 项 | 瓦片：**每天洗 / 隔天洗 / 一周两三次 / 更少** |
| genderIdentity | 下拉 | 瓦片：**女 / 男 / 其他 / 不透露** |

- 每组"暂不确定/不透露"是平等瓦片；日常打理分钟改为瓦片（**基本不打理 / 5 分钟内 / 10 分钟左右 / 20 分钟以上**→映射 0/5/10/25，另留自填）。

## 4. 第一印象（照片当主角）

- **档案空态**：真实发型样片三联做视觉锚 + 一句身份句（"你的理发记忆，只存在这台手机上"）+ 一个主按钮；信任三连（不办卡·不推销·不上传）用图标行说清。
- **首页**：无档案时首action改"先看一个真实对比示例"（/try 已有，先体验后建档，Duolingo 式）；主行动卡 elev-3 加厚；标题层级拉开。
- **Tony卡**：继承新 tokens（更大的字、更实的卡、照片更大）；本轮不改结构。

## 5. 不做

- 不改数据模型/存储值；不引新字体；不加第二强调色；
- 不做暗色模式、不做适老版独立界面（把通用界面直接做到适老指标）；
- 不加任何装饰动效/纹理/插画风背景。

## 6. 测试影响与计划

- 建档 select→radio 瓦片：全部 e2e 建档助手改 `getByRole('radio', { name: /有点弯/ }).check()`；受影响：archive、barber-brief、region-marks、share-studio、plan-memory、offline-site、hairstyle-library、v3-experience 等；
- OptionCards 单测：radio 语义、v-model、选中态、≥45px、键盘；
- 首页 action 变化：homeAction 相关单测同步；
- 回归红线：全量单测+39 e2e 全绿；390px 重拍：首页、档案空态、建档三步、计划表单、Tony卡、分享工作室。

## 7. 验收红线自检

| 红线 | 覆盖 |
| --- | --- |
| 小学生/老人不需要翻译词汇 | 画出来 + ≤5 字白话 + 一句解释 |
| 老花眼分得清层次 | 纸面/卡片两档明度差 + 柔影 + 文字对比 ≥7:1 + 主要文字 ≥17px |
| 适老化硬指标 | ≥44px 目标（本品 ≥45）、对比 ≥4.5、焦点环、无诱导按钮 |
| 品质感 | 照片圆角裁切当主角、一个强调色、键程感按钮、克制动效 |
| 先体验后建档 | 无档案首页主行动=看真实对比示例 |
| 数据零迁移 | 存储值不动，全部只改呈现层 |
