# Private Reference Regions Design

## Outcome

把私人参考图从“存一张图和一段备注”升级为可纠正的局部意图：用户只选择刘海、顶部、两侧、后脑中的相关部位，说明“喜欢这里”或“不要照搬”，再用一句短话补充。系统不识图、不推断，只把用户明确表达的局部意图带入计划快照和沟通卡。

## Experience

- 照片本地处理完成后显示四个有颜色和图标的部位按钮。
- 一次只编辑一个部位；选择“喜欢这里 / 不要照搬”并填写不超过 80 字的说明。
- 已记录部位以摘要行显示，可重新编辑或删除。
- 不强迫用户标满四项；零项仍可保存，兼容现有私人参考。
- 编辑已有参考时完整恢复；换图不擅自清除用户文字选择。
- 加入计划时，将局部意图转换为清楚的候选备注，图片快照和现有隐私边界不变。

## Data and compatibility

- 在现有 `privateReferences` 对象中增加非索引字段 `focusAreas`，不新增 Dexie 表或版本。
- 旧数据缺失该字段时按空数组读取；新写入统一验证部位唯一、类型合法、文字长度。
- 计划仍保存独立候选快照；删除私人参考不影响已建计划。

## Boundaries

- 不做 AI 视觉识别、自动部位定位、脸型推断或现实可剪性结论。
- 不上传照片、不增加 API、账号或云存储。
- 不把固定按钮伪装成照片像素级标注；它们是用户表达发型结构的快捷入口。

## Acceptance

- 新增和编辑均可保存、刷新并恢复局部意图。
- 重复部位、非法枚举和超长说明在 repository 边界拒绝且原数据不变。
- 私人参考加入计划后，候选备注包含用户明确的局部意图。
- 390px 手机无横向溢出，按钮至少 45px，可键盘操作，减少动态效果时不依赖动画。
