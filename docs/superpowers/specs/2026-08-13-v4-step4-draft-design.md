# V4 第④步建议设计草案：匿名统计 + 邮箱登录 + 云备份（未获批，只文档不代码）

日期：2026-08-13
状态：**草案**。按总纲第 5 节，本步依赖产品负责人先完成域名/ICP、服务端选型、商标确认，执行 AI 不得开工。本文只给建议方案与决策清单。

## 0. 定位

产品第一次引入服务端。原则：**本地优先不动摇**——服务端只做三件事（匿名计数、邮箱验证码、加密备份存取），任何一件挂掉，现有全部功能照常可用。

## 1. 范围建议

### 1.1 匿名统计（最小可用）

- 只统计**事件计数**，不统计用户：`app_open`、`plan_created`、`record_created`、`brief_shown_at_salon`、`share_exported(kind)`、`pwa_installed`；
- 无 userId、无设备指纹、无 IP 存储（服务端丢弃）、无第三方 SDK；一条事件 = `{event, day, appVersion}`；
- 客户端本地聚合按天批量上报，失败静默丢弃不重试堆积；
- 设置页提供「不参与统计」开关，默认状态由产品负责人决定（建议默认参与 + 首次弹一次性说明）。

### 1.2 邮箱登录（只为云备份，不设门槛）

- 邮箱 + 6 位验证码，无密码；登录**不解锁任何功能**，唯一作用是绑定云备份空间；
- 未登录用户的一切现有体验不变（红线：登录墙零处出现）；
- 验证码限频（同邮箱 60s/次、每日上限）+ 一次性使用 + 10 分钟过期。

### 1.3 云备份（端到端加密）

- 复用现有 `localBackup` 序列化产物（已含图片 Blob 与全部表）；
- **端到端加密**：客户端用用户口令派生密钥（Argon2id/PBKDF2）加密后上传，服务端只见密文——服务端被攻破也不泄漏发型照片；口令丢失 = 备份不可恢复，界面必须把这句话说清楚；
- 每账号保留最近 N 份（建议 3），手动备份 + 可选「每次剪后记录保存成功后提醒备份」；
- 恢复流程复用现有本地恢复的合并策略；跨设备迁移是核心卖点（换手机不丢 Tony 记忆）。

## 2. 不做（本步红线建议）

- 不做微信/手机号登录（涉及资质，后议）；
- 不做任何服务端可读的用户数据（照片/计划/记录明文永不上行）；
- 不做行为分析、漏斗、A/B、第三方统计 SDK；
- 不做自动后台同步（V1 手动备份，避免流量与冲突复杂度）；
- 不做多设备实时同步/协作。

## 3. 技术形态建议

- 服务端：沿用仓库已有的 Vercel Functions + Neon（`api/` 目录已有 polling 骨架与安全模板：来源校验、限频、参数化 SQL），新增 3 组端点：`/api/stats/ingest`、`/api/auth/email-code`、`/api/backup/{put,list,get}`；
- 备份存储：Vercel Blob（仓库已有依赖与封装），密文对象 + 元数据（大小/时间/校验和）；
- 鉴权：验证码换短期 JWT（仅备份端点使用）；
- 事件上报与备份上传都要有**离线容忍**：断网时不报错不阻塞。

## 4. 数据（草案）

服务端三张表：`stats_daily(event, day, count)`、`auth_codes(email_hash, code_hash, expires_at, used)`、`backups(account_id, blob_key, bytes, checksum, created_at)`。客户端 IndexedDB 零迁移（只新增 settings 键存开关与账号态）。

## 5. 需要产品负责人先拍板的决策清单

1. 域名 + ICP 备案完成时间（统计与验证码邮件的前置）；
2. 邮件发送服务选型（Resend/SES/自建 SMTP）与发件域名；
3. 统计默认开还是默认关；事件清单是否增删；
4. 备份口令丢失即不可恢复——接受端到端加密的这个代价，还是接受服务端可协助恢复（= 服务端能解密，隐私承诺降级）？**二选一，影响宣传口径**；
5. 每账号备份配额（份数 × 单份大小上限，直接决定存储成本）；
6. 商标/定名最终确认（影响邮件模板、manifest、分享角标是否要改）。

## 6. 验收红线（预填，开工前再审）

- 未登录、断网、服务端 500 三种情况下，现有全部 e2e 依然全绿（本地优先回归）；
- 统计请求体内不含任何 ID/指纹/照片字节，有网络断言 e2e；
- 备份上行字节 = 密文，服务端侧写死无解密路径；上传前后本地数据 byte-level 一致性校验；
- 验证码限频与过期有服务端测试；
- 登录墙零处出现：全站无「登录后才能 X」。
