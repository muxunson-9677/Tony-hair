# “咋剪发”Apple 浅色移动端视觉与交互设计规格

## 1. 已确认方向

本轮采用用户确认的融合方向：

- 以 A 方案的白色 iOS 图库式内容结构为骨架；
- 使用 C 方案的多彩小图标与状态颜色；
- 只在导航、浮动操作坞、弹层和短暂停驻工具栏使用 B 方案的清透玻璃；
- 手机移动端是第一验收设备，390×844 为主基准，360×800 与 430×932 为边界；
- 不使用深蓝背景、霓虹发光、全屏玻璃、玻璃套玻璃或科技仪表盘风格。

产品希望用户感到“清楚、轻松、愿意反复打开”，而不是“炫技”。人物照片和理发决策永远比材质效果更醒目。

## 2. 视觉系统

### 2.1 基础颜色

```text
页面底色      #F6F7F9
实体内容面    #FFFFFF
主要文字      #17181B
次要文字      #686E77
细分隔线      rgba(28, 34, 43, 0.09)
系统蓝        #3478F6
收藏珊瑚      #F06572
档案紫        #8768EA
完成薄荷绿    #38AE7C
提醒琥珀      #F2A63A
危险红        #D93E45
```

颜色只表达辅助含义。所有当前状态还必须同时通过文字、图标形态、`aria-current` 或 `aria-pressed` 表达。

### 2.2 材质层级

实体白色面承载：发型照片、发型详情正文、档案列表、表单、沟通卡、隐私遮罩画布、错误与空状态。

玻璃面只承载：

- 移动端底部四项导航；
- 桌面顶部导航；
- 发型图片上的返回、收藏、搜索等小型动作；
- 详情页底部操作坞；
- 筛选弹层、确认弹层和临时提示；
- 滚动后才悬浮的筛选工具条。

玻璃使用白色半透明材质、适度饱和和柔和阴影，不使用蓝黑玻璃。`backdrop-filter` 不可用或用户要求减少透明度时，退化为高不透明度白色实体面。

### 2.3 图标

导航和高频动作使用统一 20–22px 线性 SVG 图标，不使用 emoji、数字序号或文字首字母冒充图标。

图标放入 36–44px 的浅彩色圆角图标井：

- 首页：珊瑚色；
- 找发型：系统蓝；
- 档案：紫色；
- 我的/本机数据：薄荷绿；
- 收藏：珊瑚色空心/实心心形；
- 上传、搜索、筛选、返回、展示给理发师使用各自熟悉符号。

品牌剪刀 Logo 保留，但缩小为系统级识别符，不再压过页面标题与照片。

### 2.4 字体与圆角

- 使用系统中文字体栈；
- 页面标题 28–34px，负字距，紧凑行高；
- 区块标题 20–24px；
- 正文不低于 15px；
- 辅助文本不低于 12px，并保证对比度；
- 大图片 22–26px 圆角；
- 小型按钮 12–14px 圆角；
- 玻璃导航和操作坞 20–24px 圆角；
- 不把每段正文都装进大圆角卡片。

## 3. 触摸与动效系统

### 3.1 按下

- `pointerdown` 当帧反馈，不等待 `click`；
- 图标按钮缩放到 0.94–0.96，普通按钮缩放到 0.97；
- 阴影同时收紧，颜色饱和度轻微上升；
- 反馈只使用 `transform`、`opacity` 和必要的颜色变化；
- 触控目标不低于 44×44px。

### 3.2 移动与取消

- 按住后在约 10px 容差内仍视为同一次点击；
- 手指拖离目标后取消提交，拖回目标可恢复按压状态；
- 动画进行中再次按下时，从屏幕当前值开始，不等待旧动画结束；
- 所有可拖动区域用 Pointer Events 与 pointer capture 保持连续跟手。

### 3.3 拖动

横向筛选条和收藏夹轨道支持一比一跟手拖动：

- 保留手指抓取位置；
- 记录最近若干次移动的时间与位置；
- 到边缘时使用渐进阻力，不硬停；
- 页面纵向滚动意图明确时，不抢占纵向手势；
- 键盘与普通滚动仍可完成同样操作。

### 3.4 松手

- 按钮使用无明显弹跳的临界阻尼回位，约 220–320ms；
- 拖动松手继承手指速度，经过短距离动量投影后减速；
- 只有真实拖动或轻甩允许轻微回弹，普通页面进入和菜单打开不弹跳；
- 收藏成功只做图标由空心到实心、0.96→1 的轻微回弹，不做飞心和彩带。

### 3.5 减少动态

`prefers-reduced-motion: reduce` 下：

- 关闭位移、弹簧、动量与视差；
- 保留短促的颜色、透明度和状态切换；
- 不影响按钮按下可感知性和操作结果理解。

## 4. 页面落地

### 4.1 全局外壳

- 移动端底部导航为一块悬浮白色玻璃坞，考虑安全区；
- 当前项使用浅彩色图标井、图标与文字共同高亮；
- 桌面端仍保留真实宽屏布局，不把手机页面居中放大；
- 路由进入使用短促淡入与 4px 位移，支持中断和减少动态。

### 4.2 首页

- 顶部为小型品牌区和单个辅助动作；
- 真实记录照片或有效收藏作为主视觉；
- 保留由 `resolveHomeAction` 计算出的唯一主行动，不改业务优先级；
- 主行动使用系统蓝实体按钮，次要动作使用白色/浅彩色图标按钮；
- 不新增营销宫格、统计仪表盘或虚假社交数据。

### 4.3 找发型

- 两列照片流是主体；
- 搜索与筛选使用白色搜索面和可拖动筛选轨道；
- 收藏按钮浮在照片右上角，使用白色玻璃小按钮；
- 首屏仍需完整显示第一行两款并露出下一行；
- 收藏、私人参考和精选保持真实本机数据语义。

### 4.4 发型详情与私人参考

- 大图优先，信息以清晰分隔而非卡片堆叠组织；
- 收藏、加入计划、给理发师看等真实动作进入底部玻璃操作坞；
- 私人参考完整查看继续使用 `object-fit: contain`，不裁掉发型；
- 错误、保存中、处理图片和存储不可用状态保持诚实可恢复。

### 4.5 档案、记录、沟通卡与隐私遮罩

- 不改变任何 IndexedDB、图片处理、沟通卡、遮罩或计划业务逻辑；
- 表单使用白色实体面、清楚分组、彩色区块图标和系统蓝主按钮；
- 危险操作仍使用红色且与主操作分开；
- 理发师展示和沟通卡保持高对比、可打印、无玻璃正文；
- 遮罩画布不使用玻璃覆盖，工具按钮采用彩色图标井。

## 5. 技术边界

- Vue 3、TypeScript、现有 Pinia/Dexie/Router 架构保持不变；
- 不新增社区、账号、云同步、支付、投票或后端接口；
- 不新增重量级 UI 框架；
- 使用本地 SVG 图标组件、Vue 指令、Pointer Events、Web Animations API 与 CSS；
- 动效模块不合成点击，不改变原生链接、按钮、表单和键盘语义；
- 视觉改造不得改变现有路由、数据写入、图片字节、隐私与删除契约。

## 6. 验收

### 6.1 行为

- 按下当帧出现反馈；拖离取消、拖回恢复；释放回位可被再次按下打断；
- 筛选轨道跟手、松手有速度延续，纵向滚动不被错误拦截；
- 所有原有业务单元测试与端到端流程通过；
- 页面不新增 `/api/`、外域图片、WebSocket 或隐私字节请求。

### 6.2 视觉

- 390×844：首页、精选、详情、私人参考、档案、沟通卡、遮罩；
- 430×932 与 360×800：无横向溢出，底部操作不遮内容；
- 1440×900：真实宽屏布局；
- 浅色界面为主，玻璃只出现在控制层；
- 多彩图标统一、克制、可辨识，不出现 emoji 或数字导航。

### 6.3 无障碍与性能

- 普通文字 4.5:1；控件边界、图标和焦点 3:1；
- 触控目标至少 44×44px；200% 字体不裁切；
- 键盘可完成导航、搜索、筛选、收藏、上传和加入计划；
- `prefers-reduced-motion`、`prefers-reduced-transparency`、`prefers-contrast` 均有真实浏览器验收；
- 手势帧只更新合成友好属性，滚动期间无全屏持续模糊或多层玻璃。
