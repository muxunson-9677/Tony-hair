# 品质返工交付报告：视觉质量整改（2026-08-13）

## 背景

用户对上一版 UI 的判定是 20/100，核心批评：

1. **词汇抽象**——"柔和/利落/中性呈现"这类词，小学生和上年纪的用户看不懂；
2. **没有体积感**——整页白色贴白色，卡片分不出层，老花眼用户看不清；
3. **第一印象不合格**——首页和 Tony 卡撑不起"对标苹果"的品质预期；
4. 要求超出苹果单一参照，做到**巨量影响力、高质量内容、轻理解门槛、高效精准品质感**。

## 调研结论（摘要，全文见设计稿）

- **工信部《APP 适老化通用设计规范》**：正文 ≥17px（本次 mobile 基准 1rem=17px）、点击目标 ≥44px、辅助文字对比度 ≥7:1；
- **Apple HIG**：层级靠海拔（elevation）与字重，不靠颜色堆砌；蓝色只给"下一步该按的键"；
- **Airbnb DLS**：插画代替术语，选择项全部画出来；
- **Duolingo**：先体验后注册——首页给"先看一个对比示例"，不逼建档；
- **微信/张小龙**：好产品是用完即走，词汇必须白话。

## 设计论点（一句话）

> 更深的冷灰纸面上，白色卡片像实体卡片一样浮起并有厚度；文字更大更黑、层级靠字重；蓝色只出现在"下一步该按的那个键"上；红色只说"绝对不要"；所有靠眼睛做的选择都画成图。

## 本次改动清单

### 1. 设计 tokens v2（`apple-light-foundations.css`）

- 纸面 `--paper` 从 `#f6f7f9` 加深到 `#e9edf2`，白卡与背景的明度差拉开约 3 倍；
- 新增三级海拔 `--elev-1/2/3`（多层复合阴影），卡片有"厚度"；
- `html { font-size: 106.25% }`，移动端正文 17px 起；
- 主按钮改渐变 + 外阴影 + 内高光，按下有"键程感"；
- 全局焦点圈统一品牌蓝（覆盖旧橙色 `button:focus-visible`）。

### 2. 可视化选择组件（TDD，新增 5 条单测）

- `OptionCards.vue`：通用瓦片单选组，原生 radio 保证无障碍，泛型约束值类型；
- `OptionArt.vue`：18 种 SVG 线稿——发质（直/弯/卷/密卷）、粗细、发量（扇形）、洗头频率（点阵）、打理时间（时钟）、感觉（波浪线=柔和，折线=利落）、"暂不确定"（虚线圆问号）；
- 建档表单 7 个抽象下拉全部换成图卡：性别、感觉、发质、粗细、发量、洗头、打理时间；
- 打理分钟数字输入改为 5 档时间瓦片（不用/5/10/20 分钟/不确定）。

### 3. 白话文案（全站统一）

| 旧 | 新 |
| --- | --- |
| 更喜欢中性呈现 | 中性都行 |
| 细软发丝 | 发丝细 |
| 发量适中 | 发量正常 |
| 微卷 | 有点弯 |
| 01 · PERSON / 02 · CUT / 03 · TALK | 第一步 / 第二步 / 第三步 |
| DEMO_AI · 预制素材 | 这个方案的说明 |
| （英文 Details 泄漏） | 顶部、刘海和侧后的细节说明 |

### 4. 第一印象重做

- **首页（新用户）**：品牌名+承诺置顶，蓝色主键"先认识一下我的头发"，下方新增"先看一个对比示例"入口（不建档先体验），再往下是真实示例视觉；
- **档案空态**：三张示例人像叠放 + "这台设备还没有发型档案" + 三枚信任瓦片（不上传/不注册/不推销）+ 渐变主键；
- **/try 示例页**：从旧版深色编辑部风格整体重皮肤成浅色系统（这是新用户第一次点击就会看到的页面，原来是全站最大的风格断裂点）。

### 5. 语义色纪律

- Tony 卡"绝对不要"从蓝色改为红色 `#b3261e`（红=避雷，全站唯一含义）；
- "请现场确认"从蓝色改为墨色（蓝=可点，不可点的不许用蓝）；
- 步骤 2 数字圈从珊瑚红改为紫色（红不再出现在普通步骤上）；
- 理发师确认提示统一琥珀色标注条。

### 6. 对比度与细节修复

- 授权提醒正文：旧主题遗留的米色 `#c8c0b5` 印在白卡上（对比度 ~1.4:1，几乎不可见）→ 改为墨色标题+灰正文；
- `sample-disclosure`/`future-source-note` 黑底色块 → 白卡；
- 建档输入框聚焦圈：橙色 → 品牌蓝；
- Tony 卡四枚操作按钮（到店打开/分享/导出 PNG/打印）从横向滚动截断改为一屏放下。

## 对抗性自审

以 390px 截图逐页过审（资产在 `assets/2026-08-13-visual-overhaul/`）：

- ✅ 分层：纸面 `#e9edf2` 上白卡浮起，海拔三级可辨；
- ✅ 零门槛选择：发质/发量/洗头/时间瓦片不识字也能选；"感觉"瓦片重画后（波浪 vs 折线）读得懂；
- ✅ 蓝色纪律：每屏只有一个蓝色主键；红色只在"绝对不要"和删除类操作出现；
- ✅ 无英文行话泄漏（Details/PERSON/CUT/TALK/DEMO_AI 已清除）；
- ⚠️ 遗留（判断为可接受）：样式库照片顶部的文字压图 chip 依赖半透明底，极端图片下对比度可能偏低；`.eyebrow` 蓝色眉标不可点但为全站一致的品牌语言，保留。
