### ②B 避雷区域打标 V1（`2026-08-13-v4-step2b-delivery-report.md`）

- 剪后照片点选打标：区域（顶/两侧/刘海/后脑/鬓角）× 问题（太短/太薄/形状不对/衔接生硬/自定义 ≤160 字），≤5 个，纯可选不阻塞复盘；
- 记录详情三图并排：当时想剪的 / 实际剪成的 / 哪里出了问题；
- 打标进入 ① 的记忆通道（区域级条目优先于自由文本避雷）；
- 确定性冲突提示：仅同区域同问题类型精确匹配（太短↔剪更短、太薄↔打薄）才提醒，展示两条来源由用户裁决，零语义猜测。

### ③ 分享工作室（`2026-08-13-v4-step3-delivery-report.md`）

- 五类分享图（对比/复盘/避雷/Tony卡/帮我选）全部本地 Canvas 生成，3:4 = 1080×1440；
- 人像照片过本地人脸检测：单人自动遮罩、多人硬拦截、检测失败硬拦截、无人脸原样；
- 品牌角标「Tony宝 · 本地生成」，无二维码；系统分享优先、下载兜底、取消不降级；
- 入口只在三个峰值时刻（剪后保存成功、记录详情、Tony卡），首页零入口；
- e2e 断言全流程无跨域请求、无写请求；4× CPU 节流下生成 <3s。

## 4. 对抗性自审（第③步末全程复盘）

已发现并修复：

- 分享图右列中文按全宽上限截断导致画出画布外（红线「中文排版无溢出」）→ 按列宽重推上限 + 新增「任何文本不得越界」不变量单测；
- Vue reactive proxy 直接进 IndexedDB 触发 DataCloneError（②B 保存计划）→ 存储前转 plain object；
- `<details>` 响应式 open 绑定导致面板在清空选择时自动收起吞掉后续点击（②B 计划表单）→ 改一次性初始化；
- SW 预缓存占位符被压缩器改引号导致替换失败 → 放宽占位符匹配；
- 浮点累加导致 ASCII 恰好满宽时误截断 → epsilon。

遗留的诚实声明：

- 离线能力与分享面板的「真机」体验未验证（桌面模拟已全绿）；
- 低端安卓 <3s 是 4× CPU 节流的代理指标，非真机实测；
- 分享图美观度是主观项，等待终审。
